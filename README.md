# Аукцион Selectel: панель-бот

Бесплатная полупрозрачная панель поверх окон для аукциона выделенных серверов Selectel: живые лоты, скидка и цена сейчас, через 1 и 2 часа, время достижения нужной скидки, обратный отсчёт, сортировка, фильтры и группировка по железу, слежение за лотами со звуком и уведомлениями, заказ в один клик, трей, автозагрузка, самообновление.

## Скачать

В разделе Releases справа, файл под свою систему:

- **Windows**: `SelectelAuctionBot-X.Y.Z-setup.exe` — установщик в профиль пользователя, без прав администратора. Есть и переносимый `…-windows-x64.zip`.
- **Linux**: `SelectelAuctionBot-X.Y.Z-linux-x86_64.AppImage` — сделать исполняемым (`chmod +x`) и запустить.

Контрольные суммы в `SHA256SUMS.txt`. Приложение само проверяет обновления и предлагает установить новую версию.

## Как пользоваться

1. Запустите, панель появится поверх окон. Перетаскивайте за заголовок, меняйте размер уголком справа внизу, прозрачность ползунком «Фон».
2. Выберите целевую скидку в поле «Цель»: колонки покажут цену и время, когда каждый лот до неё дойдёт.
3. Нажмите «★ Следить» на интересном лоте и укажите порог: при его достижении придёт уведомление и звук.
4. Двойной клик по лоту открывает страницу заказа в браузере.

Вопросы и ошибки: раздел Issues этого репозитория.
